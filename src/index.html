💡 Mẹo nhập liệu & In ấn

Nhập liệu bảng công việc
  • Quan hệ phụ thuộc: nhập số ID dòng, mặc định FS. Hỗ trợ FS / SS / FF / SF và lag: 2FS+3 ; 5SS-1 ; 4,7
  • Nhân lực: nhập số người (12) hoặc theo tên: Nhân công[10]; Thợ hàn[2]
  • Thời gian = 0 → mốc tiến độ (milestone ◆)
  • Dán từ Excel: copy vùng ô trong Excel → click ô bắt đầu trong bảng → Ctrl+V (tự thêm dòng nếu thiếu)
  • Click tiêu đề cột = chọn toàn bộ nội dung cột · Chuột phải tiêu đề = menu (Field Settings, chèn/xóa cột…)
Header / Footer khi in
  • Định dạng từng đoạn chữ: bôi đen đoạn trong ô rồi bấm B / I / U (hoặc Ctrl+B / Ctrl+I / Ctrl+U)
  • Box footer: click chọn box trong preview → Ctrl+C copy · Ctrl+V dán · Delete xóa · kéo thả đổi vị trí
  • Token tự điền: {DUAN} {CONGTRINH} {HANGMUC} {GOITHAU} {DIADIEM} {BATDAU} {KETTHUC} {NGAYIN} {TRANG} {SOTRANG}
  • Header: dòng Giữa nằm trên; Trái + Phải hàng dưới — kéo thanh sọc giữa 2 ô để chỉnh ranh giới

🖱 Thao tác chuột
  • Click ô ID chọn dòng (Ctrl/Shift chọn nhiều) · giữ kéo ô ID di chuyển dòng/khối.
  • Click tiêu đề cột chọn cột · giữ kéo di chuyển cột · double-click đổi tên cột.
  • Kéo mép phải cột / mép dưới ô ID: giãn rộng-cao · chọn nhiều rồi kéo = đồng bộ size · double-click mép = tự vừa nội dung.
  • Chuột phải trên dòng / tiêu đề cột / thanh Gantt: menu thao tác nhanh (chèn-xóa, thu gọn nhóm, Bar Style riêng cho task).
  • Nút ▾/▸ trước tên nhóm: thu gọn / mở cấp con.
  • Cuộn ngang Gantt tới mép: trục thời gian tự nối dài vô hạn 2 chiều.
📋 Nhập liệu & ghi chú
  • Predecessors: nhập số ID, mặc định FS. Hỗ trợ FS/SS/FF/SF + lag: 2FS+3 ; 5SS-1 ; 4,7
  • Duration: chỉ nhập số, đơn vị "ngày" tự thêm. Duration = 0 → mốc tiến độ ◆.
  • Resource: số người 12 hoặc theo tên Nhân công[10]; Thợ hàn[2]
  • Start: nhập dd/mm/yyyy = ràng buộc "không sớm hơn"; xóa trống để bỏ ràng buộc.
  • Dòng chưa có tên = dòng trống, không vẽ thanh. Tối đa 500 dòng.
  • Dán từ Excel: copy vùng ô → click ô bắt đầu → Ctrl+V, tự thêm dòng nếu thiếu.
  • Duration tính theo ngày làm việc (Project → Change Working Time: tuần mặc định, giai đoạn riêng, ngày nghỉ lễ).
📄 File & dữ liệu
  • File dự án đuôi .tdtc — nhấp đúp mở trực tiếp. Mở lại cùng file sẽ cập nhật đúng dự án cũ.
  • Mọi thao tác tự lưu trong máy; Ctrl+S để lưu ra file trao đổi/dự phòng. Dấu ● cạnh tên file = chưa lưu.
  • File → My Projects: nhiều dự án song song (mở/đổi tên/nhân bản/xóa).
