💡 Mẹo nhập liệu & In ấn

Nhập liệu bảng công việc
  • Quan hệ phụ thuộc: nhập số ID dòng, mặc định FS. Hỗ trợ FS / SS / FF / SF và độ trễ: 2FS+3 ; 5SS-1 ; 4,7
  • Nhân lực: nhập số người (12) hoặc theo tên: Nhân công[10]; Thợ hàn[2]
  • Thời gian = 0 → mốc tiến độ ◆
  • Dán từ Excel: sao chép vùng ô trong Excel → bấm ô bắt đầu trong bảng → Ctrl+V (tự thêm dòng nếu thiếu)
  • Bấm tiêu đề cột = chọn toàn bộ nội dung cột · Chuột phải tiêu đề = menu (cài đặt cột, chèn/xóa cột…)
Đầu trang / Chân trang khi in
  • Định dạng từng đoạn chữ: bôi đen đoạn trong ô rồi bấm B / I / U (hoặc Ctrl+B / Ctrl+I / Ctrl+U)
  • Hộp chân trang: bấm chọn hộp trong màn hình xem trước → Ctrl+C sao chép · Ctrl+V dán · Delete xóa · kéo thả đổi vị trí
  • Token tự điền: {DUAN} {CONGTRINH} {HANGMUC} {GOITHAU} {DIADIEM} {BATDAU} {KETTHUC} {NGAYIN} {TRANG} {SOTRANG}
  • Đầu trang: dòng Giữa nằm trên; Trái + Phải hàng dưới — kéo thanh sọc giữa 2 ô để chỉnh ranh giới
Phím tắt chung
  • Ctrl+S lưu file · Ctrl+O mở file · Ctrl+Z/Y hoàn tác/làm lại · Ctrl+P xuất PDF/In · ESC trong Xem trước = quay lại thiết lập

🖱 Thao tác chuột
  • Bấm ô ID chọn dòng (Ctrl/Shift chọn nhiều) · giữ kéo ô ID di chuyển dòng/khối.
  • Bấm tiêu đề cột chọn cột · giữ kéo di chuyển cột · bấm đúp đổi tên cột.
  • Kéo mép phải cột / mép dưới ô ID: giãn rộng-cao · chọn nhiều rồi kéo = đồng bộ size · bấm đúp mép = tự vừa nội dung.
  • Chuột phải trên dòng / tiêu đề cột / thanh Gantt: menu thao tác nhanh (chèn-xóa, thu gọn nhóm, kiểu thanh riêng cho công việc).
  • Nút ▾/▸ trước tên nhóm: thu gọn / mở cấp con.
  • Cuộn ngang Gantt tới mép: trục thời gian tự nối dài vô hạn 2 chiều.
📋 Nhập liệu & ghi chú
  • Quan hệ trước: nhập số ID, mặc định FS. Hỗ trợ FS/SS/FF/SF + độ trễ: 2FS+3 ; 5SS-1 ; 4,7
  • Thời lượng: chỉ nhập số, đơn vị "ngày" tự thêm. Thời lượng = 0 → mốc tiến độ ◆.
  • Nhân lực: số người 12 hoặc theo tên Nhân công[10]; Thợ hàn[2]
  • Bắt đầu: nhập dd/mm/yyyy = ràng buộc "không sớm hơn"; xóa trống để bỏ ràng buộc.
  • Dòng chưa có tên = dòng trống, không vẽ thanh. Tối đa 500 dòng.
  • Dán từ Excel: sao chép vùng ô → bấm ô bắt đầu → Ctrl+V, tự thêm dòng nếu thiếu.
  • Thời lượng tính theo ngày làm việc (Dự án → Lịch làm việc: tuần mặc định, giai đoạn riêng, ngày nghỉ lễ).
📄 File & dữ liệu
  • Tệp dự án đuôi .tdtc — nhấp đúp mở trực tiếp. Mở lại cùng tệp sẽ cập nhật đúng dự án cũ.
  • Mọi thao tác tự lưu trong máy; Ctrl+S để lưu ra file trao đổi/dự phòng. Dấu ● cạnh tên file = chưa lưu.
  • Tệp → Dự án của tôi: nhiều dự án song song (mở/đổi tên/nhân bản/xóa).

Cột tùy chỉnh được thêm sau cột Nhân lực — nhập tự do, hỗ trợ wrap text, dán từ Excel và có mặt trong danh sách "Cột cần xuất" khi in. Xóa cột sẽ xóa cả dữ liệu trong cột đó.
